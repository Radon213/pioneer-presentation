# Pioneer · ICCAS 2026 presentation

Public presentation snapshot with continuous Three.js scenes.

- Presentation: https://radon213.github.io/pioneer-presentation/
- Right / Space: next stage. Left: previous stage. Hold an arrow for fast navigation.
- F: fullscreen. S: presenter notes in a separate window. Use an extended display for presenting.
- A current desktop browser with WebGL is required. Recorded simulation and FEA are replayed in Three.js; a simulation server is not required.

This is an ongoing research presentation. Recorded motion and illustrative FEA replay are not clinical validation or proof of assistance benefit.

Only runtime dependencies are included. Research archives, Blender projects, older versions and unrelated workspace files are excluded. This repository is a snapshot; local changes do not automatically publish.

Third-party notices are in THIRD_PARTY_NOTICES.md and the corresponding source directories.
