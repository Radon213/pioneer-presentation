# Pioneer presentation working repository

This Git repository is the working source for the public GitHub Pages presentation. Make subsequent presentation edits here, rather than in the earlier template-review snapshot.

- Edit examples/pioneer-draft/deck-data.js, modules and style.css. Generate index.html with npm run build; do not edit the generated HTML directly.
- Preserve the academic cream/serif theme, English audience headings, left visual/right copy composition, presenter-only notes and one continuous Three.js scene. Keep navigation controls out of the slides except the small stage indicator.
- Preserve native component ownership, original colours, left/right reflection and source motion. Never duplicate POS5 geometry or portray illustrative replay as validated assistance.
- For every model or animation change, consider transfer size, parsing/memory, setup and frame costs. Keep research originals outside this public runtime repository and retain their provenance.
- Run npm run build, npm test, npm run manifest and npm run check before committing. Rebuild the manifest whenever runtime files change.
- main is the configured GitHub Pages source. Commit and push authorized changes here, then verify the deployed version; a local commit alone does not update the site.
